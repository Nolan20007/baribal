# Ежедневный отчёт BARIBAL на Timeweb

Скрипт хранится вне публичной папки сайта: `baribal/baribal-private/daily-report.php`.
Почтовая конфигурация рядом: `baribal/baribal-private/baribal-mail.json`.
Оба файла размещаются GitHub Actions при деплое Timeweb. Пароли в репозитории не хранятся.

## Настройка расписания

После первого успешного деплоя:

1. Откройте панель Timeweb → **Crontab** → **Добавить задачу**.
2. Название: `BARIBAL — ежедневный отчёт`.
3. Выберите PHP-интерпретатор, совместимый с PHP 8.4 (или ту же версию, что выбрана для сайта).
4. Через файловый менеджер выберите файл `baribal/baribal-private/daily-report.php`. Не размещайте его в `public_html`.
5. Часовой пояс: **Europe/Moscow**.
6. Расписание: **понедельник–пятница, 17:00**.
7. Сохраните и включите задачу.

Скрипт дополнительно проверяет московское время и день недели, использует MySQL-блокировку от параллельного запуска и сохраняет дату успешной отправки. Повторный запуск в тот же день не отправит дубликат; при ошибке отправки следующий запуск сможет повторить попытку.

## Состав письма

- Поступившие за день заявки и их текущие статусы.
- Накопительные заявки в статусах «Новое» и «В работе».
- Общее число заявок, которые требуют внимания.
- Количество отзывов, ожидающих модерации.

Отчёт отправляется с `zayavki@baribal-studio.ru` на `info@baribal-studio.ru` через приватную SMTP-конфигурацию.

## Важно

GitHub-деплой размещает скрипт и конфигурацию, но не создаёт задачу Crontab автоматически. Задачу нужно включить в панели Timeweb после первого деплоя.
