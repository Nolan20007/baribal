## Правило для будущих изменений

Не переписывать и не «улучшать» рабочий экстрактор без необходимости. Не менять селекторы Creatium, обход предков карточки, поиск CSS background-image, выбор главного изображения по видимой площади, последовательность клика по миниатюрам Fancybox и проверку полноразмерных файлов только потому, что код кажется необычным.

Если через неделю или позже снова работаем с извлечением фотографий:
1. Сначала прочитать этот файл и `maintenance/README.md`.
2. Использовать существующий workflow **Extract and archive Creatium galleries**.
3. Для новой карточки менять только номера карточек и, если нужно, необязательный текст-предохранитель.
4. Не трогать код, пока обычный запуск не показал конкретную воспроизводимую проблему.
5. Любое необходимое изменение проверять на одной известной карточке и убеждаться, что сохранены и main image, и все доступные дополнительные оригиналы.

## Рабочая схема

- Источник: `https://baribal-studio.ru/`.
- Скрипт: `maintenance/tools/extract-creatium-images.mjs`.
- Workflow: `.github/workflows/extract-creatium-images.yml`.
- Нормализация/индекс: `maintenance/tools/normalize-creatium-galleries.mjs`.
- Индекс: `maintenance/creatium-gallery-index.json`.
- Дополнительные оригиналы: `assets/images/portfolio/galleries/`.

### Запуск

GitHub → Actions → **Extract and archive Creatium galleries** → Run workflow.

- First card to process: номер карточки.
- Last card to process: тот же номер для одной карточки; диапазон — для нескольких.
- Maximum additional gallery photos per card: **0** (meaning every discovered gallery photo; positive values set an optional cap).
- Optional text check: пусто либо уникальная строка из нужной карточки.

Workflow запускает Playwright/Chromium, скачивает главное изображение и дополнительные оригиналы, выполняет дедупликацию SHA-256, обновляет индекс и коммитит новые ресурсы. Скачанные исходные результаты доступны в артефакте `creatium-gallery-source`.

Локальный эквивалент для карточки №8:

```bash
npm install
npx playwright install chromium
PAGE_URL=https://baribal-studio.ru/ CARD_START=8 CARD_END=8 GALLERY_LIMIT=0 node maintenance/tools/extract-creatium-images.mjs
node maintenance/tools/normalize-creatium-galleries.mjs
```

## Почему алгоритм именно такой

На карточке №8 Mercedes-Benz GLE Coupe главное изображение не находилось среди обычных `<img>`: оно было задано CSS-свойством `background-image` внутри контейнера карточки. Скрипт поднимается от кнопки «Все фото» по предкам, ищет контейнер с «Все фото» и (если задан) текстом карточки, собирает видимые CSS backgrounds и изображения, затем выбирает крупнейший по видимой площади кандидат. Название Mercedes-Benz GLE Coupe больше не зашито в код: фильтр `REQUIRED_CARD_TEXT` необязательный и передаётся из формы запуска.

Дополнительные фотографии в Creatium представлены ссылками на Fancybox. Миниатюры могут быть прозрачными или низкого разрешения, поэтому скрипт кликает по каждой ссылке и извлекает полноразмерное изображение из просмотрщика/сетевого ответа. Не заменять этот способ простым скачиванием href или миниатюр.

## Подтверждённый контрольный пример

Карточка №8 — Mercedes-Benz GLE Coupe, повторная проверка после исправления выбора галереи:
- активная модалка: `.modal0-root.is-active`;
- найдено ссылок внутри модалки: **3** (не 8 ссылок общей сетки проектов);
- главное фото: SHA-256 `a58165e7f70299a15a7ca5f55c623020b4190ebe69f09d124ab5bdd9d3eae3b8`, 212 208 байт;
- дополнительных оригиналов: **3 из 3**;
- SHA-256 дополнительных файлов:
  - `760f52fe35ff8702c47501873ce0d7363d54895d149d5983acab9af632d1d8f7`;
  - `d1c3405fac34ce652af2ca2e1443cb41b8798be0491419c24ec5e85aea36df23`;
  - `e07619d016a9cf994c3a88f261b674ea13202d2a301cd032299eae535e0f1f59`.

Итоговый индекс карточки №8 содержит ровно 1 главное фото и 3 дополнительных. Предыдущий ошибочный результат (8 ссылок из общей сетки) заменён корректными данными в индексе. Физические старые файлы не удалялись, поскольку архив ресурсов append-only; они не перечислены в актуальной записи карточки №8.

Успешная проверка: [GitHub Actions run 44241706036](https://github.com/Nolan20007/baribal/actions/runs/44241706036).
