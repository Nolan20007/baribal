# Служебные инструменты BARIBAL

## Фотографии портфолио — обязательное правило

**Единственная действующая инструкция:** [PHOTO-MIGRATION-RULES.md](PHOTO-MIGRATION-RULES.md).

Перед любой работой с фотографиями портфолио прочитать её целиком. Она определяет отдельно проверенные процессы для обложек и галерей, успешные запуски GitHub Actions, запрещённые способы и обязательную проверку опубликованного сайта.

Старые инструкции по фото удалены, чтобы не было противоречивых указаний. Не создавать параллельные инструкции и не менять рабочую процедуру без проверки успешных запусков.

## Служебные инструменты

- `tools/` — скрипты обслуживания и миграции. Перед запуском читать исходный код и проверять, для какого диапазона и типа фотографий он предназначен.
- `cover-approved.json` — manifest вручную подтверждённых обложек для workflow импорта.
- `cover-candidates.json` — кандидаты обложек, ещё не являющиеся подтверждёнными.
- `creatium-gallery-index.json` — индекс перенесённых галерей.
- `creatium-image-inventory.json` и `creatium-localization-report.json` — инвентаризация и отчёт локализации ресурсов.
- `asset-audit.md` — журнал проверки ресурсов.

Содержимое `maintenance/` не является частью сайта. В production публикуется сайт из штатного deploy workflow.
