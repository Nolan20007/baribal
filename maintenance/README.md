# Служебные инструменты BARIBAL

Эта папка предназначена для скриптов разработки, переноса и проверки материалов.

## Извлечение фотографий Creatium — ЗАФИКСИРОВАННЫЙ РАБОЧИЙ ИНСТРУМЕНТ

**Не менять алгоритм извлечения, селекторы, порядок кликов, логику выбора главного изображения и настройки Playwright без конкретной причины и отдельной проверки на исходном сайте.** Это рабочая связка, восстановленная после отладки карточки Mercedes-Benz GLE Coupe (карточка №8). Если вернулись к задаче через время — сначала прочитать `maintenance/CREATIUM-EXTRACTOR-LOCK.md`.

Основной скрипт: `maintenance/tools/extract-creatium-images.mjs`.

### Как запустить для любой карточки

1. Открыть GitHub → Actions → **Extract and archive Creatium galleries**.
2. Нажать **Run workflow**.
3. Указать:
   - **First card to process** — номер первой карточки;
   - **Last card to process** — номер последней карточки (для одной карточки указать тот же номер);
   - **Maximum additional gallery photos per card** — оставить `0`: это означает без ограничения, сохранить все найденные дополнительные фотографии (главная сохраняется отдельно);
   - **Optional text check** — оставить пустым, либо вписать уникальный текст из карточки для защиты от ошибки выбора.
4. Запустить workflow и дождаться статуса **Success**. Workflow сам скачает Chromium, откроет старый сайт, извлечёт главное фото и дополнительные оригиналы, дедуплицирует их по SHA-256, обновит индекс и закоммитит архив.
5. Проверить в логе итоговые значения, а также файл `maintenance/creatium-gallery-index.json`: у нужного `cardIndex` должны быть заполнены `mainImage` и `gallery`. В Actions → run можно скачать артефакт `creatium-gallery-source` с исходным отчётом.

**Важно:** значение `0` означает «захватить все найденные дополнительные фотографии»; положительное число задаёт верхний предел. Главная фотография сохраняется отдельно. Скрипт не сохраняет маленькие превью как оригиналы. Если число ссылок в активной модалке не совпадает с ожидаемым, снимки не обнаружены или карточка не прошла проверку текста, считать запуск неуспешным и изучить лог. Статус GitHub Actions Success сам по себе не доказывает, что выбрана правильная галерея.

### Что делает скрипт

- Находит карточки по порядку элементов «Все фото».
- Определяет главную фотографию. На Creatium она может быть не тегом `<img>`, а CSS `background-image`; поэтому скрипт обходит контейнер карточки и выбирает крупнейший видимый кандидат.
- Открывает галерею и ищет ссылки только внутри активного модального окна выбранной карточки. Не использует общую сетку проектов или все Fancybox-ссылки страницы.
- Кликает по ссылкам миниатюр и проверяет полноразмерные оригиналы из просмотрщика (минимум 500×300 px), а не миниатюры.
- Сохраняет главное фото отдельно от дополнительных.
- Нормализатор `normalize-creatium-galleries.mjs` считает SHA-256, переиспользует дубли и обновляет индекс, не удаляя ранее сохранённые файлы.

### Локальный запуск

Требуется Node.js 22, зависимости проекта и Chromium Playwright:

```bash
npm install
npx playwright install chromium
PAGE_URL=https://baribal-studio.ru/ CARD_START=8 CARD_END=8 GALLERY_LIMIT=0 node maintenance/tools/extract-creatium-images.mjs
node maintenance/tools/normalize-creatium-galleries.mjs
```

Для проверки другой карточки меняются только `CARD_START` и `CARD_END`. При необходимости можно добавить `REQUIRED_CARD_TEXT="уникальный текст карточки"`.

## localize-creatium-assets.mjs

Скачивает изображения, на которые ссылается текущий код сайта, проверяет формат и контрольную сумму SHA-256, удаляет бинарные дубли и заменяет ссылки на локальные ресурсы.

- Источник списка: `creatium-image-inventory.json`.
- Результат: `assets/images/` и `creatium-localization-report.json`.
- Автоматический запуск: workflow `Localize Creatium assets`.
- Не нужен на Timeweb: это инструмент миграции/обслуживания.

## normalize-creatium-galleries.mjs

Служебный второй этап извлечения, автоматически вызывается workflow после основного скрипта.

- Вход: `output/creatium-images/cards/`.
- Выход: `assets/images/portfolio/galleries/` и `creatium-gallery-index.json`.
- Физические файлы галерей append-only: автоматическое удаление не выполняется.

## Другие файлы

- `creatium-image-inventory.json` — исходный список внешних URL и мест их использования.
- `creatium-localization-report.json` — отчёт о скачанных локальных изображениях и их SHA-256.
- `asset-audit.md` — журнал ревизии ресурсов.

**Важно:** содержимое `maintenance/` не является частью сайта. На Timeweb загружается только production-сборка `dist/`.
