# Служебные инструменты BARIBAL

Эта папка предназначена для скриптов разработки, извлечения и проверки материалов.

## extract-creatium-images.mjs

Скрипт Playwright для извлечения изображений и галерей со старого сайта Creatium.

- Запуск: `npm run extract:creatium`
- Требует установленный Playwright и переменную окружения `PAGE_URL`.
- Результаты создаёт в `output/creatium-images/`.
- Используется только при ревизии/переносе контента. На опубликованном сайте и на Timeweb не нужен.

Workflow, который запускает этот скрипт по расписанию или вручную, хранится в `.github/workflows/extract-creatium-images.yml`, поскольку GitHub Actions распознаёт workflow только из этой папки.

## Важно

Содержимое `maintenance/` не является частью сайта. На Timeweb загружается только собранная папка `dist/`.
