# BARIBAL — подключение мониторинга рейтингов

Рабочая ветка: `main`. Публичный сайт на GitHub Pages и PHP-админка Timeweb — разные контуры. Этот раздел относится к PHP-сайту на Timeweb.

## Текущий статус
- Создана вкладка «Рейтинги» в админке.
- Добавлена таблица `baribal_rating_snapshots` для хранения ежедневных снимков и истории.
- Пока ни одна площадка не помечается подключённой без фактически проверенного официального источника.
- Сбор данных не использует парсинг HTML, headless browser или обход ограничений.

## Официальные способы
- Google Maps: Places API (New), поля `rating` и `userRatingCount`. Нужны Google Cloud API key и Place ID. Документация: https://developers.google.com/maps/documentation/places/web-service/place-details
- Яндекс: рейтинг обновляется ежедневно; доступны виджеты для сайта и личный кабинет. Не считать виджет полноценным серверным API. Документация: https://yandex.ru/support/business-priority/ru/reviews/rating
- 2ГИС: личный кабинет позволяет сгенерировать официальный виджет рейтинга, который показывает текущую оценку и количество отзывов. Для серверной истории запросить у 2ГИС подтверждённый официальный API/экспорт; публичный API не отдаёт поле рейтинга. Документы: https://dostavili.2gis.ru/public/0424/biz/ и https://help.2gis.ru/question/otkuda-beryotsya-reyting-kompaniy

## Что потребуется для полного автоматического режима
1. Google Places API key и Place ID карточки Baribal.
2. Подтверждённый способ Яндекса для серверного получения рейтинга (либо согласовать, что Яндекс показывает живой официальный виджет, а история пока не строится).
3. Код официального виджета 2ГИС из кабинета Baribal и письменное/документированное подтверждение API/экспорта, если он доступен для этой организации.
4. Добавить секреты только в приватный файл Timeweb `baribal-private/baribal-mail.json`; никогда не коммитить их в Git.

## Таблица
`baribal_rating_snapshots`: provider, rating, review_count, checked_at, source, status, error_code. Таблица создаётся автоматически при первом подключении к базе через `baribalLeadDatabase()`.
