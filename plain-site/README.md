# BARIBAL — plain HTML version

Изолированная новая версия сайта на обычных HTML, CSS и JavaScript. Она не заменяет опубликованный сайт и пока не подключена к GitHub Pages.

## Структура
- `index.html` — главная страница.
- `tehnology/index.html` — полный каталог 15 услуг.
- `kuzov/index.html` — услуги по защите кузова.
- `himchistka/index.html` — химчистка салона.
- `avtovinil/index.html` — оклейка виниловой плёнкой.
- `foto/index.html` — портфолио из 60 проектов.
- `video/index.html` — видеостраница с четырьмя плеерами.
- `reviews/index.html` — отзывы и демонстрационная форма отзыва.
- `politika-konfidencialnosti/index.html` — политика конфиденциальности.
- `css/style.css` — стили.
- `js/main.js` — мобильное меню, выбор услуг, галереи и демонстрационная обработка форм.
- `../assets/` — общая папка с изображениями и видео, файлы не копируются.

## Принципы
- Все страницы — статические HTML-файлы с обычными относительными ссылками.
- Никаких Vite, npm, импортов модулей или обязательной сборки.
- CSS перенесён из действующей версии; пути к ресурсам адаптированы для вложенной структуры.
- Изображения портфолио открываются в исходном размере в новой вкладке.
- Видеостраница использует общий файл `assets/video/studio.mp4` с нативными элементами управления.
- Формы пока работают в режиме предпросмотра: реальная отправка заявок и отзывов требует отдельного серверного обработчика.

## Безопасность старого проекта
- Корневые файлы действующего сайта и ветка `main` не изменены.
- `maintenance/`, `output/`, `archive/` и `.github/workflows/` сохранены.
- Скрипты извлечения Creatium и нормализации галерей не изменялись.
- Новая версия пока не опубликована и не заменяет действующий сайт.

## Проверки
- Пути к ресурсам внутренних страниц сверены с деревом репозитория: отсутствующих файлов не найдено.
- У внутренних страниц нет дублирующихся HTML id и битых внутренних якорей.
- JavaScript проходит синтаксическую проверку.
- Визуальная проверка в реальном браузере ещё не выполнена.
