# BARIBAL — plain HTML version

Изолированная новая версия сайта на обычных HTML, CSS и JavaScript. Она не заменяет опубликованный сайт и пока не подключена к GitHub Pages.

## Структура
- `index.html` — главная страница.
- `css/style.css` — стили.
- `js/main.js` — небольшой JavaScript для мобильного меню.
- `../assets/` — общая папка с изображениями и видео, файлы не копируются.

## Принципы
- Изображения подключаются обычными прямыми путями, например `../assets/images/portfolio/...`.
- Никаких Vite, npm, импортов модулей или обязательной сборки.
- CSS перенесён из действующей версии, чтобы сохранить уже разработанный визуальный стиль; пути к ресурсам адаптированы для вложенной папки.
- Основные разделы главной страницы уже собраны в статическом HTML.
- Ссылки на изображения в карточках портфолио открывают исходный файл в новой вкладке.

## Безопасность старого проекта
- Корневые файлы действующего сайта не изменены.
- `maintenance/`, `output/`, `archive/` и `.github/workflows/` сохранены.
- Скрипты извлечения Creatium и нормализации галерей не изменялись.
- Новая версия пока не опубликована и не заменяет `main`.
