# BARIBAL — plain HTML version

Новая версия сайта на обычных HTML, CSS и JavaScript. Папка изолирована от действующей версии.

## Файлы
- `index.html` — главная страница.
- `css/style.css` — стили.
- `js/main.js` — обычный JavaScript без сборщика и зависимостей.

## Ресурсы
Изображения пока используются напрямую из общей папки `../assets/`. Фотографии не дублируются.

## Важно
- Текущая версия сайта в корне репозитория не изменена.
- `maintenance/`, `.github/workflows/`, `output/` и архивы не изменены.
- Скрипты извлечения фотографий Creatium остаются на прежних местах без изменений.
- Новая версия пока не подключена к GitHub Pages и не заменяет опубликованный сайт.
