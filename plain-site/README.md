# BARIBAL — plain HTML version

Основная версия сайта BARIBAL сделана на обычных HTML, CSS и JavaScript и публикуется через GitHub Pages из папки `plain-site/`.

## Страницы
- `index.html` — главная.
- `tehnology/index.html` — каталог услуг.
- `kuzov/index.html` — защита кузова.
- `himchistka/index.html` — химчистка салона.
- `avtovinil/index.html` — автовинил.
- `foto/index.html` — портфолио из 60 проектов.
- `video/index.html` — тестовая видеогалерея.
- `reviews/index.html` — отзывы.
- `politika-konfidencialnosti/index.html` — политика конфиденциальности.

## Функции
- Мобильное меню, светлая/тёмная тема и кнопка «Наверх».
- Калькулятор с 15 услугами и синхронизацией выбранных позиций.
- Модальные окна обратного звонка и подробных описаний услуг.
- Портфолио с фильтрами, показом всех работ и фотогалереями.
- Фирменный BARIBAL-плеер с тестовыми превью и собственными элементами управления.
- Кнопка «Тестовый блок» только на больших экранах: предпросмотр ширины телефона, ноутбука и широкого монитора.
- В тестовом блоке есть ссылка на прежнюю Vite-версию.

## Старый Vite-проект
Исходный проект сохранён в ветке `vite-archive`. Для удобства он также собирается в отдельный раздел GitHub Pages: `/baribal/vite-archive/`. В нём сохранён прежний дизайн и навигация; основная HTML-версия не зависит от Vite.

## Важные ограничения
- `assets/video/studio.mp4` сейчас имеет размер 0 байт. Плеер и тестовые превью восстановлены, но для воспроизведения нужно вернуть исходный MP4.
- Формы работают в демонстрационном режиме и показывают подтверждение на странице. Реальная отправка заявок и отзывов требует отдельного серверного обработчика.
- Визуальная проверка в реальном браузере ещё не выполнялась; успешная сборка GitHub Actions сама по себе не подтверждает каждый экран визуально.
- Переключатель четырёх альтернативных дизайнов не используется: оставлен утверждённый основной дизайн.
