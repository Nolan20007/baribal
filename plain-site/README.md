# BARIBAL — plain HTML version

Изолированная новая версия сайта на обычных HTML, CSS и JavaScript. Она не заменяет опубликованный сайт и пока не подключена к GitHub Pages.

## Структура
- `index.html` — главная страница.
- `tehnology/index.html` — полный каталог 15 услуг.
- `kuzov/index.html` — услуги по защите кузова.
- `himchistka/index.html` — химчистка салона.
- `avtovinil/index.html` — оклейка виниловой плёнкой.
- `foto/index.html` — портфолио из 60 проектов.
- `video/index.html` — видеостраница с аккуратным сообщением о подготовке роликов; исходный `assets/video/studio.mp4` пока пустой (0 байт).
- `reviews/index.html` — отзывы и демонстрационная форма отзыва.
- `politika-konfidencialnosti/index.html` — политика конфиденциальности.
- `css/style.css` — стили.
- `js/main.js` — мобильное меню, выбор услуг, галереи, всплывающее окно обратного звонка, подробные карточки услуг, фильтры портфолио, переключение светлой/тёмной темы, кнопка «Наверх» и демонстрационная обработка форм.
- `../assets/` — общая папка с изображениями и видео, файлы не копируются.

## Принципы
- Все страницы — статические HTML-файлы с обычными относительными ссылками.
- Никаких Vite, npm, импортов модулей или обязательной сборки.
- CSS перенесён из действующей версии; пути к ресурсам адаптированы для вложенной структуры.
- Портфолио содержит 60 проектов, фильтры по направлениям и раскрытие полного списка; изображения открываются в исходном размере в новой вкладке.
- На всех страницах восстановлены окно обратного звонка, переключение светлой/тёмной темы и кнопка «Наверх».
- В каталоге услуг и разделе защиты кузова восстановлены подробные окна описания услуг с преимуществами, технологией, рекомендациями и кнопкой заказа.
- Сохранён только утверждённый основной дизайн; переключателя альтернативных дизайнов в новой версии нет.
- Видеоплееры не показываются, пока в репозитории нет реального видеофайла: `assets/video/studio.mp4` имеет размер 0 байт. После добавления роликов можно вернуть нативные плееры.
- Формы пока работают в режиме предпросмотра: реальная отправка заявок и отзывов требует отдельного серверного обработчика.

## Безопасность старого проекта
- Корневые файлы действующего сайта и ветка `main` не изменены.
- `maintenance/`, `output/`, `archive/` и `.github/workflows/` сохранены.
- Скрипты извлечения Creatium и нормализации галерей не изменялись.
- Новая версия пока не опубликована и не заменяет действующий сайт.

## Проверки
- Пути к ресурсам и относительные ссылки всех HTML-страниц сверены с деревом репозитория: отсутствующих файлов не найдено.
- Проверены обработчики мобильного меню, демонстрационных форм, обратного звонка, переключения темы, фильтров портфолио и кнопки «Наверх»; стили внутренних страниц и мобильные брейкпоинты присутствуют.
- Фото на странице химчистки заменено на проект Toyota Camry, который в исходных данных отмечен как полировка и химчистка.
- У внутренних страниц нет дублирующихся HTML id и битых внутренних якорей.
- JavaScript проходит синтаксическую проверку.
- Визуальная проверка в реальном браузере ещё не выполнена.
