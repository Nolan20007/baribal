# BARIBAL — сайт студии защитных технологий

Проект для разработки и предпросмотра сайта BARIBAL.

## Запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

## Страницы

- `/` — главная страница
- `/video` — видео студии

## Интеграции

Формы в локальном предпросмотре демонстрационные. Перед публикацией их необходимо подключить к обработчикам Creatium. Текущая версия не отправляет персональные данные и не заявляет об успешной отправке заявок.
