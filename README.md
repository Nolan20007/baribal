# BARIBAL — сайт студии защитных технологий

Исходный проект сайта BARIBAL. Репозиторий содержит исходники, ресурсы, архивные материалы и отдельные инструменты обслуживания.

## Разработка

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
npm run preview
```

Обычная сборка рассчитана на размещение сайта в корне домена (например, на Timeweb).

Для сборки предпросмотра GitHub Pages используется переменная окружения:

```bash
GITHUB_PAGES=true npm run build
```

GitHub Actions выставляет её автоматически. Путь GitHub Pages остаётся `/baribal/`, а сборка для Timeweb использует `/`.

## Страницы

- Главная и внутренние разделы формируются приложением из `src/main.js`.
- Видео: `/video`.
- Дополнительные разделы: услуги, технологии, портфолио, отзывы и политика конфиденциальности.

## Формы

Формы в текущей версии демонстрационные: они не отправляют реальные заявки. Перед запуском на основном домене нужно подключить и протестировать обработчик заявок.

## Структура репозитория

- `src/` — код сайта и стили.
- `maintenance/` — скрипты обслуживания, не нужные посетителям сайта.
- `archive/` — архивные материалы и превью, не попадающие в production-сборку.
- `.github/workflows/` — автоматизация GitHub; workflow-файлы должны оставаться в этой папке.

На Timeweb нужно загружать содержимое production-сборки `dist/`, а не весь репозиторий. Файл `public/.htaccess` автоматически попадёт в `dist/` и настроит Apache на отдачу `index.html` для внутренних маршрутов сайта.
